## GOLFBROTHERS 迁移模式规则（强制）

### 1. 核心目标

当前任务是：

> 将已有 HTML / 片段代码迁移为微信小程序代码

必须满足：

- UI 结构尽量一致
- 交互逻辑完全不改变
- 数据结构不重构

---

### 2. ❌ 禁止行为（非常重要）

Cursor 不允许：

- ❌ 重写业务逻辑
- ❌ 优化数据结构
- ❌ 改变交互流程
- ❌ 改 UI 风格系统
- ❌ 删除任何已有 UI 元素
- ❌ 合并/拆分业务模块

---

### 3. ✅ 允许行为

Cursor 只允许：

- ✔ HTML → WXML 转换
- ✔ CSS → WXSS 转换
- ✔ JS 迁移为小程序 JS
- ✔ DOM事件 → bindtap 等适配
- ✔ 适配小程序生命周期
- ✔ 修复兼容性问题

---

### 4. UI复刻原则（核心）

必须做到：

> 视觉结构优先级 > 小程序规范

也就是说：

- 允许“写得不优雅”
- 不允许“改得不像原页面”

---

### 5. 逻辑保持原则

所有逻辑必须：

- 保持函数名语义一致
- 保持计算方式一致
- 保持数据流方向一致

禁止“优化算法”
