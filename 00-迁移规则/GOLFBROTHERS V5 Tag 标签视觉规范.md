# GOLFBROTHERS V5 Tag 标签视觉规范

版本：V5.0  
适用范围：

- 赛事详情
- 创建比赛
- 报名流程
- 分组管理
- 记分页面
- 球员信息
- 首页赛事卡片

# 1. Tag 基础结构规范

所有标签统一采用：

```
Icon（可选）+文字
```

结构：

```
┌────────────┐│  图标  文案 │└────────────┘
```

---

## 1.1 尺寸规范

- 属性
- 分类

# 2. Tag 分类体系

GOLFBROTHERS 标签分为 5 类：

---

# A. Selection Tag（选择标签）

## 语义

> 用户当前选择状态。

关键词：

- 已选择
- 当前
- 激活

例如：

```
正式队员嘉宾男女四人四球个人比杆
```

---

## 未选状态

### BRIGHT

背景：

```
#F5F6F8
```

边框：

```
#D9DEE7
```

文字：

```
#5B6472
```

### DARK

背景：

```
#252A32
```

边框：

```
#46505C
```

文字：

```
#B8C0CC
```

---

## 已选状态

统一：

BRIGHT / DARK：

背景：

```
PGA Blue#005BAC
```

文字：

```
#FFFFFF
```

边框：

```
PGA Blue
```

可增加：

```
✓
```

---

## 禁用状态

背景：

灰色透明

文字：

弱化灰

```
opacity:0.45
```

---

## 使用场景

✅ 报名分组  
✅ 性别选择  
✅ 赛制选择  
✅ 比赛结构选择

---

# B. Status Tag（状态标签）

## 语义

> 表示赛事或流程状态。

例如：

```
报名中进行中已结束已关闭待确认
```

---

## 状态颜色

## 进行中

PGA蓝：

```
#005BAC
```

文字：

白色

---

## 成功状态

绿色：

```
#21A366
```

例如：

```
已完成已确认
```

---

## 警告状态

金色：

```
#C89B3C
```

例如：

```
报名即将截止等待确认
```

---

## 关闭/异常

红色：

```
#D64545
```

例如：

```
报名关闭取消比赛
```

---

# C. Info Tag（信息标签）

## 语义

> 描述对象属性，不代表状态。

例如：

```
18洞男子女子北京队四人四球蓝T
```

---

## 颜色

BRIGHT：

背景：

```
#E8F2FC
```

文字：

```
#005BAC
```

DARK：

背景：

```
#183047
```

文字：

```
#7FB8FF
```

---

## 使用原则

Info Tag 不可表达：

❌ 已选择  
❌ 已完成  
❌ 权限身份

---

# D. Identity Tag（身份标签）

## 语义

> 表示用户角色、组织身份。

例如：

```
队长创建者管理员认证球员
```

---

## 使用颜色

冠军金：

背景：

```
#C89B3C
```

文字：

```
FFFFFF
```

---

## 注意

金色不是普通强调色。

禁止：

```
正式队员嘉宾普通球员
```

使用金色。

---

# E. Achievement Tag（荣誉标签）

## 语义

> 成绩、荣誉、排名。

例如：

```
冠军MVP最佳球员TOP10
```

---

颜色：

冠军金：

```
#D4A72C
```

文字：

白色。

---

# 3. 金色标签使用限制

金色代表：

```
稀缺价值荣誉身份
```

所以：

允许：

✅ 冠军  
✅ MVP  
✅ 队长  
✅ VIP

禁止：

❌ 男  
❌ 女  
❌ 已报名  
❌ 四人四球  
❌ 正式队员

---

# 4. PGA蓝标签使用限制

PGA蓝代表：

```
主动确认当前选择主要操作
```

允许：

✅ 已选择  
✅ 确定  
✅ 当前TAB  
✅ 进行中

禁止：

❌ 普通分类信息

例如：

```
18洞男子北京队
```

不要用PGA蓝。

---

# 5. DARK模式统一原则

禁止：

不同颜色体系。

例如：

错误：

BRIGHT：

蓝色选中

DARK：

黑色选中

正确：

BRIGHT：

```
选中=PGA蓝
```

DARK：

```
选中=PGA蓝
```

变化：

只改变：

- 背景；
- 边框；
- 未选状态。

---

# 6. 标签与按钮区别

必须区分：

## Button

动作：

```
确定创建保存添加
```

有点击行为。

---

## Tag

状态：

```
男18洞报名中正式队员
```

表达信息或选择。

---

不要：

把按钮设计成 Tag。

不要：

把 Tag 当按钮。

# 7. GOLFBROTHERS Tag 快速判断表

| 问题          | 答案  | 类型          |
| ----------- | --- | ----------- |
| 用户正在选择它吗？   | 是   | Selection   |
| 它表示比赛当前状态吗？ | 是   | Status      |
| 它只是说明属性吗？   | 是   | Info        |
| 它表示身份等级吗？   | 是   | Identity    |
| 它表示荣誉成绩吗？   | 是   | Achievement |
